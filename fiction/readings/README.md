# Readings of the system articles

One file per Encyclopaedia Galactica system article, named by the article's
id, holding everything a reader found in it that carries a year or names a
holder: every event with the sentence it was read from, holders named without
a year, names that matched no polity, contradictions as pairs of quotes, and
doubts. `BRIEF.md` is the instruction the readers worked from and defines the
shape.

These are kept whole, unreviewed, because a timeline this fine-grained does
not exist anywhere else: the Encyclopaedia's own history pages date some
1,600 events for the whole Terragen Sphere, and these files date a system's
own ships, schisms, plagues and wormholes. What the map draws is the reviewed
subset, written into `worlds.yaml` with the quote on each event; an event that
is here and not there was judged not to be a change of the system's presence
or holder, or to be a sub-settlement within a settled system, and nothing
more than that.

Provenance: read by a cheaper model (Sonnet) from the article's prose, one
article at a time, in 2026-09; reviewed by the session's main model at the
diff. A polity id here is one from `polities.yaml`; a name that matched none
is under `unplaced`. Years are After Tranquility as written, never converted.
